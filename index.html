Como funciona: o app extrai **características ópticas** do ROI (médias de R/G/B, razões R/G e G/B e o **PI** da PPG) e, com **2–3 pontos de calibração** (digitando a temperatura real medida por um termômetro), ajusta uma regressão para estimar a temperatura de pele. É útil para tendências sob a mesma iluminação e câmera; não substitui um termômetro.

  • Recomendo 3 pontos: mão fria (~30–32°C pele), normal (~33–34°C), aquecida (~35–36°C). Use o mesmo local (dedo/rosto) e luz constante.
  • Trocas de iluminação/câmera invalidam a calibração. Faça nova calibração se algo mudar.
  • Temperatura de pele é inferior à central; valores absolutos não servem para triagem clínica.
Boas práticas & limitações
  • Este app é educacional; não é um dispositivo médico.
  • Para PPG: fique imóvel 20–30 s; não pressione demais; mantenha o dedo aquecido e seco.
  • PI aqui é um proxy de perfusão periférica — útil para tendências, não para valores absolutos.
  • Iluminação constante é crítica para qualquer estimativa baseada em cor.
Código único, sem dependências externas. getUserMedia + Canvas + regressão linear (ridge) em JS.
