  • Compatível com o serviço Health Thermometer (0x1809). Nem todos os termômetros BLE usam esse padrão.

Boas práticas & limitações
  • Este app é educacional; não é um dispositivo médico. Não use para decisões clínicas.
  • Para PPG: fique imóvel por 20–30 s; não pressione demais; mantenha o dedo aquecido e seco.
  • PI (AC/DC) aqui é um proxy de perfusão periférica — útil para tendências (antes/depois), não para valores absolutos.
  • Movimento, luz variável, esmalte escuro, pele fria/suor degradam o sinal; arrítmias podem afetar a FC.
  • Temperatura de pele ≠ temperatura central; siga as instruções do termômetro para triagem de febre.
